MP2 is a REST API which is built using FastAPI and works with CSV datasets. Clients send HTTP requests and the API validates and cleans the data reusing the MP1 data pipeline, returning a JSON response. GET /health checks and returns the application's status and version. POST /upload accepts a CSV file, stores it in memory, and returns its ID along with metadata. Files that are not CSVs are rejected with a 400 error. GET /datasets/{dataset_id} returns up to limit rows from a stored dataset along with its total row count, and returns a 404 error if the ID does not exist. POST /datasets/{dataset_id}/process takes cleaning settings as a JSON body, validates the dataset with the MP1 validate_dataframe function, and cleans it with process_data. It then replaces the stored dataset with the cleaned version and returns a cleaning report. The API also uses middleware that logs every request with a request ID, the method, path, status code, and how long it took, and sends the request ID back. The API is tested using pytest and TestClient to check that uploading, processing, and retrieving datasets work correctly.
